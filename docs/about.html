About

I'm Viba, a backend engineer, and this is my lab notebook for understanding how software systems actually work — most posts start as something I couldn't properly explain, so I take it apart, build a small toy version when I can, and write down what holds up, with references.

I write to learn: if I can't explain it here, I don't understand it yet. Expect systems, backend engineering, and notes on the technical books I'm reading.

Under the Microscope — a personal register, not a publication.
